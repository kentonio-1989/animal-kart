# どうぶつカートラッシュ! (ANIMAL KART RUSH)

どうぶつたちがカートで走る、ドット絵のレースゲームです。ブラウザで開くだけで遊べます。

**遊ぶ → https://kentonio-1989.github.io/animal-kart/**

## 遊び方
- ↑ アクセル / ↓ ブレーキ / ← → ハンドル(WASD も可)
- Space ジャンプ&ドリフト(曲がりながら押しっぱなし → 離すとターボ)
- Z アイテム(↓+Z で後ろへ) / C 後ろを見る / Esc ポーズ / M 音のオン・オフ
- ゲームパッドにも対応(パソコンのキーボードかゲームパッドで遊びます)

## どうぶつとアイテム
- ポチ(イヌ)・ミケ(ネコ)・ケロスケ(カエル)・ピヨ(ヒヨコ)・ゴンタ(クマ)・ミミ(ウサギ)・タンタン(パンダ)・トラキチ(トラ)
- ダッシュにんじん・にんじん×3・どろんこ・けいとだま・おっかけハチ・シャボンだま・ながれぼし
- コース: ぽかぽか はらっぱ / ラクダさばく / よるのネコまち

## つくり
- 元のゲーム「KART RUSH!」を作者の了承を得て改作しました。
- ドット絵は Codex(画像生成)で描き、`tools/build_sprites.py` で切り出して `js/atlas.js` にまとめています。
- 音楽・効果音・動物の鳴き声は Web Audio でプログラム合成しています(音声ファイルはありません)。
- ライブラリは使っていません(WebGL2 と Canvas のみ)。文字は Google Fonts の DotGothic16。
